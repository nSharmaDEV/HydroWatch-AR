# Logo-matched font

Montserrat Bold (700) and Medium (500), Latin WOFF2, are a geometric-sans **approximation**, not an
identification of the original WAVE logo typeface. The repository's logo is PNG
artwork, with an SVG contour trace (`assets/wave-logo-traced.svg`); no original
font file or editable text is supplied. Bold is used for provider titles and the welcome
glossary terms; Medium for the welcome glossary explanations.

Unmodified font and license from `@fontsource/montserrat@5.2.6`:
- https://cdn.jsdelivr.net/npm/@fontsource/montserrat@5.2.6/files/montserrat-latin-700-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource/montserrat@5.2.6/files/montserrat-latin-500-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource/montserrat@5.2.6/LICENSE

Served locally, with no runtime request to a font service. See
`montserrat-LICENSE.txt` for the SIL Open Font License 1.1.
