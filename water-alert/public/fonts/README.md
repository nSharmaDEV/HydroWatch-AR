# Logo-matched font

Montserrat Bold (700) and Medium (500), Latin WOFF2, are a geometric-sans **approximation**, not an
identification of the original WAVE logo typeface. The repository's logo is PNG
artwork, with an SVG contour trace (`assets/wave-logo-traced.svg`); no original
font file or editable text is supplied. Bold is used for provider titles and the welcome
glossary terms; Medium for the welcome glossary explanations.

Unmodified font and license from `@fontsource/montserrat@5.2.6`:
- https://cdn.jsdelivr.net/npm/@fontsource/montserrat@5.2.6/files/montserrat-latin-700-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource/montserrat@5.2.6/files/montserrat-latin-500-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource/montserrat@5.2.6/LICENSE

Served locally, with no runtime request to a font service. See
`montserrat-LICENSE.txt` for the SIL Open Font License 1.1.

## Body-font trial

Noto Sans normal, variable weights 400–700, Latin WOFF2 (Google Fonts v42),
is used for non-heading interface text in English and Spanish. Existing heading
families and logo artwork are preserved. Size and line-spacing rules are unchanged.
The font is self-hosted; no runtime Google Fonts requests are made.

- Font: https://fonts.gstatic.com/s/notosans/v42/o-0bIpQlx3QUlC5A4PNB6Ryti20_6n1iPHjc5a7duw.woff2
- License source: https://github.com/google/fonts/blob/main/ofl/notosans/OFL.txt
- Local license: `noto-sans-LICENSE.txt` (SIL Open Font License 1.1).

## Home display headings

Manrope Bold (700) and ExtraBold (800), Latin WOFF2, are used only for the Home page's
display headings (800: hero headline, footer name; 700: action-card titles). Self-hosted, because the app's
Content-Security-Policy allows fonts from `'self'` only; no runtime Google Fonts requests.

Unmodified fonts and license from `@fontsource/manrope@5.2.8`:
