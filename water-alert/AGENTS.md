# Water Alert agent guidance

Follow the root agent guidance and the user's current Water Alert direction.

## Required changelog updates

Every implementation change in this app must include an update to
`water-alert/CHANGELOG.md` in the same work batch, before reporting completion.
This includes features, fixes, UI changes and backend/configuration changes.

- Add a concise entry under `Unreleased`, dated when implemented.
- Describe the actual change; do not present planned work as completed.
- Distinguish local implementation/testing from deployed or verified delivery.
- Preserve existing history and limitations; do not overwrite previous entries.
