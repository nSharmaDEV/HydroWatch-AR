      Design review notes

      Less reading, clearer actions

      Only the selected route appears. Phone, full email, and official websites use chips; limitations stay next to the action.

      No live claims

      All notice states are synthetic. A current-record variant marks where authoritative published facts belong, without inventing incident instructions or address coverage.

      Original source dates

      Supplier directory, CDC and recovery resources: October 14, 2026. ADH program contact: October 18 in existing guide. None reverified for this review. Checked does not mean staffed now.

      Continuity, not persistence

      Follow-up carries compatible billing answers. Back and language switches retain edits here. Drafts are keyed by context/destination so a new request never overwrites another. Reload/close loses everything. No storage, downloads, clipboard, mail client, or external navigation.

      Remaining production gates

      Separate implementation approval; fresh official-source verification; fluent Spanish review; real notice-context integration; five exact supplier IDs; return-to-card disclosure/focus parity; regression and export testing. These screens are design proposals, not approved app changes.
